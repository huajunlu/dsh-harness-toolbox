六层安全围栏

🔒 回环围栏
全部 API 仅接受本机请求，跨站标记与异源 Origin 直接拒绝
🎫 一次性 nonce
升级/重启需 10 分钟时效一次性凭据，用后即废，CSRF 无从谈起
🚫 零 shell 拼接
固定包名 + 版本白名单正则，命令不经 shell，注入无门
📦 升级前备份
package.json 与 lock 先备份，失败自动恢复并重建依赖树
🕵️ 零密钥
不读凭据文件，代理变量只报存在性，诊断复制不含令牌
🧱 模块隔离
单模块故障只降级自身，设置页永不白屏
🧩

可持续扩展：加一个功能只需两步

宿主 lib/modules/ 新文件 + 注册表一行；页签 TABS 数组一行 —— 模块化注册表架构，互不耦合、独立隔离。
